## 功能包介绍
**`sjq:`** 包含（建图、多点导航、目标检测）相关启动文件以及参数的功能包

### 核心文件介绍
```
.
├── CMakeLists.txt
├── launch  ----------------------------- launch文件夹
│   ├── gmapping.launch  ---------------------- 建图启动文件
│   └── navigation.launch  -------------------- 导航启动文件
├── maps  ------------------------------- 导航地图文件夹
├── param  ------------------------------ 地图与规划器参数文件夹
├── rviz  ------------------------------- rviz配置文件
├── scripts  ---------------------------- rospy脚本文件夹
│   ├── init_pose.py  ------------------------- 初始化导航位姿
│   ├── read_yolo_res.py  --------------------- 读取yolo检测结果, 发布导航点
└── └── yolov5  ------------------------------- 目标检测
```
